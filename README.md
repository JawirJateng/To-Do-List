# Personal Task Manager

Aplikasi web **Personal Task Manager** untuk mengelola tugas kuliah, pekerjaan, dan kebutuhan pribadi secara terorganisir, minimalis, dan responsif.

## Fitur Utama

- **Dashboard Interaktif**: Ringkasan statistik tugas (total, pending, selesai), daftar tugas deadline terdekat, dan tugas terbaru.
- **CRUD Lengkap**: Tambah, edit, lihat detail, dan hapus tugas dengan mudah.
- **Status Tugas**: Tandai tugas sebagai selesai atau belum selesai dengan checkbox interaktif yang langsung memperbarui dashboard.
- **Kategori & Prioritas**: Pengelompokan tugas berdasarkan kategori (Kuliah, Pekerjaan, Personal) dan tingkat prioritas (Low, Medium, High).
- **Pencarian & Filter**: Cari tugas berdasarkan judul/deskripsi, filter berdasarkan kategori, status, prioritas, serta berbagai opsi pengurutan.
- **LocalStorage**: Penyimpanan data otomatis di browser pengguna tanpa memerlukan backend database eksternal.

## Teknologi yang Digunakan

- **HTML5**
- **CSS3** (Custom properties, Flexbox, Grid, Responsive Design)
- **Vanilla JavaScript (ES6+)**
- **LocalStorage API**
